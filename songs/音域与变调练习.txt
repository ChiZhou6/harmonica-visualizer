TITLE=音域与变调练习
// 本音（白）：八个键全弹一遍，8 = 高音1（, 键）
1 2 3 4 5 6 7 8 -
// 降调（绿）：长按鼠标左键再弹
b1 b2 b3 b4 b5 b6 b7 -
// 半音（紫）：长按鼠标中键再弹
#1 #2 #3 #4 #5 #6 #7 -
// 升调（蓝）：长按鼠标右键再弹
^1 ^2 ^3 ^4 ^5 ^6 ^7 -
// 半音+降调（黄）：同时按住鼠标中键 + 左键再弹
#b1 #b2 #b3 #b4 #b5 #b6 #b7 -
// 半音+升调（红）：同时按住鼠标中键 + 右键再弹
#^1 #^2 #^3 #^4 #^5 #^6 #^7 -
