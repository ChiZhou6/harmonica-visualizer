三角洲行动 · 口琴可视化曲谱  使用说明（完全不需要懂代码）
================================================================

【怎么启动】
双击 "三角洲口琴曲谱.exe" 就行，不用安装任何东西。
启动后屏幕上会出现一条半透明的深色长条（左边是控制面板，右边是 8 条音符通道）。

如果杀毒软件报警：这是打包程序的常见误报，选择"允许运行 / 添加信任"即可。
（程序只做两件事：在屏幕上画一个置顶窗口、读一下你的键鼠状态。）

第一次运行时 Windows 可能弹一个蓝色窗口"Windows 已保护你的电脑"：
点左边的"更多信息"，再点右下角"仍要运行"就行。
（这是因为程序没有花钱买数字签名，未签名的 exe 都会这样提示，属正常现象。）

★ 两个使用条件（实测总结，很重要）：
  ① 游戏显示模式选「无边框窗口」或「窗口化」——独占全屏会盖住悬浮窗口；
  ② 建议右键 exe →「以管理员身份运行」，否则全屏状态下可能读不到按键。

----------------------------------------------------------------
【认识窗口：左边是面板，右边是曲谱】

┌──────────────┬───────────────────────────────┐
│ 控制面板      │   音符通道区（8 条）           │
│（可以直接用   │   音符块从下往上堆叠           │
│  鼠标点击）   │   最下面的那个就是要弹的音      │
│              │                               │
│  曲谱列表     │                               │
│  热键按钮     │                               │
└──────────────┴───────────────────────────────┘
                                灯带（贴着游戏琴键上沿）

左边面板从上到下依次是：
  · 当前曲名 / 还剩几个音没弹
  · 六个音调指示灯：本音 / 降调 / 半音 / 升调 / 半+降 / 半+升
    ——当前按下的是哪个组合，哪个就亮
  · 一行"输入检测"——你按任何被监听的键，这里会显示"检测到：XXX"
  · 曲谱列表——点一下直接切歌，当前曲目高亮
                曲谱多到一屏放不下时，列表右边会自动出现一条滚动条：
                可以用鼠标滚轮翻，也可以直接拖那条滑块，或者点滚动条的空白处翻一页
  · 热键按钮——每个按钮右边写着对应的快捷键，**点一下就等于按了那个快捷键**
                按钮从上到下按快捷键号排：【跟随演奏】【隐藏窗口】【下一首】
                【调整窗口】【从头重来】【面板穿透】【添加曲谱】【退出程序】
                （【添加曲谱】是用来"自己录一首曲子"的，见后面章节）
                ※ 点【隐藏窗口】= 把窗口全部收起来（和按 Shift+F6 一样）。
                  为了防误点，点下去会先显示 0.8 秒的提示告诉你恢复方式，
                  然后再收起来 —— 看到提示记住 Shift+F6 就行了。

★ 热键也能用鼠标点了。不想记快捷键就点按钮。
★ 所有 F 区快捷键都要按住 Shift（Shift+F3 / Shift+F5 ~ Shift+F12），面板上每个按钮右边
  都写着它自己的键，一眼就能看到，不用背。

----------------------------------------------------------------
【第一次使用：对齐按键（只需做一次，位置会自动记住）】

1. 进游戏，掏出口琴，游戏画面下方会显示 8 个琴键。
2. 点面板上的【调整窗口】按钮（或按 Shift+F8）——窗口变成金黄色虚线框。
3. 按住窗口空白处拖动，把它拖到游戏口琴按键的"正上方"；
   再拖窗口的边缘/四角来缩放，让窗口里 8 条竖线与游戏的 8 个按键一一对齐。
4. 关键一步：窗口最底部有一条细横线（我们叫"灯带"）。
   把窗口上下调好，让这条线正好贴在游戏琴键区的上沿。
5. 再点一次【调整窗口】（或按 Shift+F8）锁定。
   位置和大小会自动存进 config.json，下次启动就在原位，不用再调。

  ※ 窗口最小只能缩到 420 × 360 左右——这是为了保证面板里的曲谱列表和
    按钮都还放得下（面板不够高时按钮会自动变矮，绝不会挤成一团或者被切掉）。

----------------------------------------------------------------
【两种演奏模式】（点面板【跟随演奏】按钮或按 Shift+F5 切换）

▍经典模式（默认，就是以前的堆叠消除）

8 个琴键对应的按键是：z  x  c  v  b  n  m  ,
音符块上直接写着该按哪个键，看块就知道按什么。

音符块不在屏幕上"掉落"，而是全部从下往上堆在你面前：
  · 最靠近底部的那一个块带白色描边 —— 它就是"现在要弹的音"
  · 按对它对应的键 → 这个块消失，整叠音符整体往下落一层，下一个块成为目标
  · 按错了 → 该通道会闪一道红光，音符不会消失（不用慌，重新按对的键就行）
  · 全部弹完会显示"演奏完成"，1 秒后自动从头开始

  ★ 方块长度（V9.2 新增）：觉得音符块太长或太短，可以把它们整体拉长 / 缩短。
    · 范围 50% ~ 200%（100% = 原样），按 Shift+↓ 缩短 10%、Shift+↑ 拉长 10%；
    · 也可以点主面板下方小面板上的【− 缩短】【＋ 拉长】按钮
      （那个小面板在经典 / 录音模式下显示的就是"方块长度"，跟随模式下显示的是"倍速"）；
    · 只改块的长短，**宽度不变**；长音仍然按比例更长（块长 = 拍数 × 单位长度）；
    · 录音模式下，窗口底部那排"已录音符"小方块也跟着一起变大变小；
    · 只影响经典模式，跟随模式不受影响（跟随模式的块长由拍数和下落速度决定）。

▍跟随演奏模式（音符跟着节奏下落，像音游）

适合标注了完整节奏的曲谱（例如 Dr-hydra 曲谱库导出的谱，见后文）。
音符块会**按真实时值从上方落下来**，落到窗口底部灯带（判定线）的那一刻，
就是该弹这个音的时刻：

  1. 切到跟随模式后**不会立刻开始**——窗口会显示"弹对第一个音「x」开始"。
  2. 把第一个音的键按对 → 开始 3 秒倒计时（这次点击不会消掉任何块）。
  3. 倒计时结束 → 音符开始下落，在判定线处按键即可。
  4. 按对 → 音符消除；按错或没接住 → 该音变暗漏过，节奏继续（不会卡住）。
  5. 全部弹完显示"演奏完成"。

  ★ 每个音都要"按住不放"才算完成 —— 这是跟随模式的重点（口琴本来就要长按）：
    · 按下的一瞬间矩形**不会消失**，只算"接住了"，矩形外面会亮起一圈描边；
    · 矩形继续往下走，判定线把它一点点"吃掉"——按住多久，就被吃掉多少；
      这个音有几拍，就要按住几拍（超短的音也至少按 0.15 秒，免得手指还没感觉就过去了）；
    · 一直按到整块吃光，这个音才算完成；
    · 中途松手 → 剩下的部分变暗漏过（手指抖一下没关系：松开 0.2 秒内又按回来不算断）；
    · **同一个键连着好几个音时，一直按着不放就行** —— 不用松开重按：按着的那个音
      被吃光后，下一个同键的音会自动接上（和真实口琴一样，按住就吹）。
    · 想改手感：config.json 里的 hold_min_seconds（最短按住秒数，默认 0.15）、
      hold_grace（松手宽限，默认 0.2 秒）。

  ★ 倍速（V9 新增）：跟随模式可以调快调慢 —— 练熟了加速、跟不上就减速。
    · 按 Shift+↑ 加快 10%、Shift+↓ 减慢 10%，范围 20% ~ 200%（100% = 原速）；
    · 也可以直接点主面板**下方那个小面板**上的【＋ 加快】【− 减慢】按钮，
      小面板上会实时显示当前倍速（它紧贴在主面板底下，一起显示/隐藏）；
    · 倍速会让音符下落变快、要按住的时长也跟着变短，但音符之间的间距不变、不会跑出屏幕；
    · 倍速只在跟随模式生效，经典模式不受影响 —— 切到经典 / 录音模式后，
      **同一个小面板会自动换成"方块长度"**（按钮也变成【− 缩短】【＋ 拉长】，
      见下面经典模式一节）。

  ※ 什么时候用哪个：刚上手 / 想慢慢对着弹 → 经典模式；
    曲谱带节奏、想练真实施奏感 → 跟随演奏。
  ※ 下落速度、判定宽严、倒计时秒数、倍速都能在 config.json 里调
    （follow_speed / follow_window / hold_min_seconds / hold_grace / follow_rate /
     countdown_seconds，见【想调外观 / 手感】）。倍速平时用 Shift+↑/↓ 调最顺手。

块的长短 = 这个音要按多久（跟随模式下每个音都要按住）：
  · 矮块 = 短音，按一下很快就被吃掉
  · 长块 = 长音，要按住不放（块越长按越久）

块的颜色 = 要配合的鼠标键（和游戏里灯带颜色一致）：
  白色块  → 正常弹，不用按鼠标
  绿色块  → 长按鼠标左键再弹（降调）
  紫色块  → 长按鼠标中键再弹（半音）
  蓝色块  → 长按鼠标右键再弹（升调）
  黄色块  → 同时按住鼠标中键 + 左键再弹（半音+降调）
  红色块  → 同时按住鼠标中键 + 右键再弹（半音+升调）

窗口底部的灯带会实时显示你当前按住的是哪种音调（白/绿/紫/蓝/黄/红），
用来确认自己有没有按对。

【快捷键】（都可以点面板按钮代替）

  ⚠️ 重要：所有 F 区快捷键都要**按住 Shift 再按**（Shift+F3 / Shift+F5 ~ Shift+F12）。
     因为游戏里也经常用 F4~F12，加了 Shift 就不会互相抢键、不会误触发。
     例：想隐藏窗口 = 按住 Shift 不放，再按一下 F6。

  ★ Shift + F6
                一键隐藏 / 恢复「全部窗口」（游戏里临时让开视野用）
                两个键效果完全一样，哪个顺手按哪个。
                隐藏时窗口位置、大小、置顶状态都原样记住，再按一下就回来；
                连打开着的曲谱编辑器也会一起收起来，不会留个窗口挡视野。
  Shift + F7    换下一首曲子
  Shift + F8    调整模式（拖动、缩放窗口）；再按一次锁定
  Shift + F9    从头重来
  Shift + F5    切换 经典模式 / 跟随演奏模式
  Shift + ↑     跟随模式：倍速 +10%（最快 200%）
                经典 / 录音模式：方块长度 +10%（最长 200%）
  Shift + ↓     跟随模式：倍速 -10%（最慢 20%）
                经典 / 录音模式：方块长度 -10%（最短 50%）
  Shift + F10   面板可点击 / 面板也鼠标穿透
  Shift + F11   打开 / 关闭【曲谱编辑器】（自己做曲谱用，见下一节）
  Shift + F12   开始 / 结束 录音（弹一遍就把曲谱录下来）
  Shift + F3    把刚录下来的曲谱存进曲谱库（★ 录完直接按它就行，不用切窗口）
  Ctrl + Alt + Q    退出程序（也可以点面板上的【退出程序】）

  ※ 不想按 Shift？用记事本打开 config.json，把 hotkeys 里的 "shift+" 删掉即可，
    例如 "next_song": "f7"。（但那样就又和游戏抢键了）

  ※ 面板上每一行按钮右侧都写着它对应的快捷键，改完 config.json 会自动跟着变。

----------------------------------------------------------------
【鼠标穿透：为什么窗口不挡游戏】

这个程序其实是"两个贴在一起的小窗口"：

  ① 右边音符区 —— 鼠标**永远穿透**，点击直接传给游戏，绝不挡操作
  ② 左边控制面板 —— 鼠标可点（按钮、曲谱列表都在这里）

  两个窗口永远贴在一起，拖动 / 缩放时会一起动，看起来就是一个整体。
  因为面板是"实心按钮"，点它时这一次点击会被面板吃掉、不会漏给游戏，
  所以点按钮不会让你在游戏里误开一枪。

  点【面板穿透】按钮（或按 Shift+F10）可以让面板也变成穿透状态、彻底不接鼠标，
  专心打游戏。

  ※ 注意：面板一旦穿透，它自己也点不动了（这是必然的），按钮文字会变成
    "已穿透"、右边写着 "Shift+F10"来提醒你 —— 按一下 Shift+F10 就能恢复可点击。
    如果连 Shift+F10 都不想按，Ctrl + Alt + Q 也能退出程序。

  小提醒：鼠标放在面板上滚轮会翻曲谱列表，不会传给游戏。

----------------------------------------------------------------
【曲谱放在哪？（★ 现在可以自己换地方了）】

默认就在**程序旁边的 songs 文件夹**里，一个 .txt 文件 = 一首曲子。
程序启动时自动读取里面全部 txt；按 Shift+F7 或在面板曲谱列表里点选。
在 songs 文件夹里手动丢一个 .txt 进去也照样能识别。

想放到别的地方（比如 D:\我的曲谱、或者某个网盘同步文件夹）：
  · 按 Shift+F11 打开【添加 / 编辑曲谱】窗口
  · 点【曲谱文件夹…】→ 选一个文件夹 → 曲谱就从那里读写了
  · 点【打开文件夹】→ 直接弹出资源管理器，方便往里放 / 往外拷
  · 想换回默认：再点【曲谱文件夹…】，选回程序旁边的 songs 文件夹即可
  · 如果新文件夹是空的，程序会问你要不要把自带曲谱复制过去

  ※ 记录存在 config.json 的 "songs_dir" 里：
      留空（""）        = 用程序旁边的 songs（推荐，跟着程序走）
      写路径            = 就用那个文件夹（可以写 D:\我的曲谱 这种绝对路径，
                          也可以写 songs2 这种相对程序目录的相对路径）

▍分享给别人的时候

  把整个文件夹打包发过去（三角洲口琴曲谱.exe + songs + config.json +
  使用说明.txt 一起），对方解压双击就能用，曲谱也一起带过去了。

  反过来，别人给你一首 .txt 曲谱：丢进 songs 文件夹，或者
  按 Shift+F11 →【从文件导入…】→ 再【保存到曲谱库】。

▍目前自带 5 首

  1. See You Again   2. 小星星       3. 欢乐颂
  4. 父亲（筷子兄弟） 5. 音域与变调练习

《See You Again》是按网上的键盘谱转写的，全 9 段共 97 个音。
《父亲》这首里有很多 ^ 开头的音（例如 ^1 ^3 ^5），意思是"按住鼠标右键
再按对应的键"，在窗口里显示为蓝色块——和网上那种键盘谱图里"数字头上带
小圆点"是同一个意思（图例写着"右键 = 高音"）。不带 ^ 的（白色块）就是
不按鼠标直接按。

▍支持「Dr-hydra 曲谱库」的谱面格式（自动识别，直接丢进 songs 就能用）

GitHub 上的开源项目 Delta-Force-Harmonica（作者 Dr-hydra）可以把 MIDI 转成
"人可演奏版文本谱"，长这样：

    念张师 主旋律 — 三角洲口琴谱
    BPM 135 · 387 音符 · 188 小节 · 移调 0

    键位标记：+ 升调（鼠标右键） / - 降调（鼠标左键） / # 半音（鼠标中键）

    小节  12 (3/4)
      简谱  #6. 2
      键位  N-# X
      节奏  8   4

这种谱面带完整节奏标注，**程序会自动识别**（不用改任何设置）：
  · 丢进 songs 文件夹，或用编辑器的【从文件导入…】都行
  · "键位"列的 Z X C V B N M , 直接对应 8 个按键，+ - # 就是升调/降调/半音
  · 因为带节奏信息，这类曲谱配合【跟随演奏模式】（Shift+F5）体验最佳——
    音符会按真实时值下落，像玩音游一样跟着节奏弹
  · 小提示：文本谱里没有记录"休止符"的确切位置，个别小节内的音可能比
    原曲稍微提前一点点；小节与小节之间的长短是精确的，不影响跟弹

曲谱写法（就是简谱，很直白）：
  1 2 3 4 5 6 7 8  → 八个音，分别对应 z x c v b n m , 八个键，各占 1 拍
  数字后面加 -      → 这个音延长 1 拍（例：5 - -  表示 5 这个音弹 3 拍）
  b 加在数字前面     → 降调（例：b5）
  # 加在数字前面     → 半音（例：#2）
  ^ 加在数字前面     → 升调（例：^1）
  #b 加在数字前面    → 半音+降调（例：#b5，黄色块；写成 b#5 也一样）
  #^ 加在数字前面    → 半音+升调（例：#^1，红色块；写成 ^#1 也一样）
  0                → 停一拍（休止符）
  |                → 小节线，只是为了好看，随便写

文件开头的两行可以设置（不写也能用）：
  BPM=90          留着的字段，这一版用不到，写不写都不影响
  TITLE=曲名

例子：
  TITLE=小星星
  1 1 5 5 6 6 5 -
  4 4 3 3 2 2 1 -

----------------------------------------------------------------
【自己做曲谱：录一遍就会】

不用打字、不用懂格式：**自己弹一遍，程序就帮你记下来。**

▍怎么录一首新曲子

1. 点面板上的【添加曲谱】按钮（或按 Shift+F11），会弹出一个小窗口"添加 / 编辑曲谱"。
2. 在最上面那行填曲名（例如：朋友）。
3. 点【● 开始录音】（或直接按 Shift+F12）。
   这时曲谱窗口上方会出现红点和"录音中"，下面还会一行一行列出你刚弹的音。
4. 进游戏，掏出琴，把这首曲子里**该按的键按顺序弹一遍**：
     · 白音就直接按 z x c v b n m ,（不用按鼠标）
     · 高音就"按住鼠标右键 + 按对应的键"，低音按左键，半音按中键
     · 半音+降调 = 同时按住鼠标中键 + 左键，半音+升调 = 同时按住中键 + 右键
   —— 和正常演奏完全一样，程序只是"看着你按"，不会干扰游戏。
5. 弹完再按一次 Shift+F12 结束录音。
6. **最快的一步：直接按 Shift+F3**（不用切出游戏！）曲谱就存好了，曲名自动叫"我的曲谱"。
7. 想改名字、想检查内容：按 Shift+F11 打开小窗口慢慢弄 ——
     检查一下文本框里的音符对不对。
     按错了 → 点【撤销一个音】（或按 Ctrl+Z），退掉最后一个音继续录。
     想全部重来 → 点【清空】。
8. 点【保存到曲谱库】（或按 Ctrl+S）—— 曲谱就会出现在左边面板的列表里，
   直接就能弹了（不用重启程序）。

▍为什么保存有两个键（Shift+F3 和 Ctrl+S）

  Shift+F3  ← 游戏在前台时也能按（它靠"读按键"工作，不需要窗口在前台）。
             所以录完直接 Shift+F3 最省事。曲名重复时会自动叫"我的曲谱2"，不会打断你。
  Ctrl+S  ← 只能在小窗口处在最前面时按（这是 Windows 窗口快捷键的规矩）。
             如果你按了 Ctrl+S 没反应，就是小窗口没在最前面 —— 用鼠标点一下
             小窗口再按，或者干脆按 Shift+F3。

▍小窗口里其它几个按钮

  撤销一个音    退掉最后录入的一个音（Ctrl+Z 也行）
  清空          把文本框清空重录（曲谱库里已保存的文件不受影响）
  载入当前曲谱   把面板上当前选中的那首曲子读进来 → 可以改它、再另存为新曲子
  从文件导入…    读取电脑上任意位置的 .txt 曲谱文件（别人给你的曲谱也能用）
  保存到曲谱库   存进当前曲谱文件夹（同名会问你要不要覆盖）
  导出为文件…    存到你想放的地方（例如桌面、发给朋友）
  曲谱文件夹…    换一个文件夹当曲谱库（详见上面【曲谱放在哪】）
  打开文件夹    用资源管理器打开当前曲谱文件夹

▍提醒

  · 录音的按键来源和平时完全一样（只读按键状态），安全性质没有任何变化。
  · 录音时文本框是锁住的（防止打字和录音打架），结束录音后就能随便改。
  · 录音会**写在文本框现有内容的后面**。要重录请先点【清空】。
  · 在曲谱文件夹里手动加 .txt 也照样能识别，程序启动时会自动读。
  · Shift+F3 保存时如果曲名和已有的重复，会自动叫"曲名2"（不弹框打断你）；
    手动点按钮或 Ctrl+S 保存时才会问你"要不要覆盖"。

【想调外观 / 手感】

用记事本打开 config.json 就能改，常用几项：

  opacity            窗口整体透明度，0.5 = 很淡，1 = 完全不透明
  hit_line_offset    灯带距离窗口底边的像素，微调对齐用
  panel_width        左侧面板宽度，默认 168（觉得挤就调大，如 200）
  panel_interactive  面板是否可点击；改成 false = 面板也不接鼠标（按 Shift+F10 可切回）
  songs_dir          曲谱文件夹；留空 = 程序旁边的 songs（详见上面【曲谱放在哪】）
  note_keys          8 个通道绑定的按键，默认 ["z","x","c","v","b","n","m","comma"]
                     逗号 = comma，句号 = period。将来游戏改键就改这里
  keyboard_monitor   设成 false 则完全不读取键鼠（灯带恒白、快捷键也失效，纯视觉）
  mode               演奏模式："classic" = 经典（默认）/" follow" = 跟随演奏
                     （平时直接点面板按钮或 Shift+F5 切换即可，会自动记住）
  leader_block_scale 经典模式音符块长度，默认 1.0 = 100%，范围 0.5 ~ 2.0（50% ~ 200%）
                     只缩放块的长短（宽度不变），长音仍按比例更长；
                     平时用 Shift+↑/↓ 调就行，改这里也可以
  follow_speed       跟随演奏模式的音符下落速度（像素/秒），默认 200
                     觉得太快看不清就调小（如 150），觉得太慢就调大
  follow_lead        倒计时结束后，第一个音还要多久落到判定线（秒），默认 2.0
  follow_window      判定窗口（秒），默认 0.20——按键时刻离音符到达判定线的时刻
                     相差不超过这个值就算命中。嫌判定太严就调大（如 0.3）
  hold_min_seconds   跟随模式下最短要按住多久才算"吃掉了"（秒），默认 0.15
                     每个音都要按住、时长按它自己的拍数算；只有超短的音才用到
                     这个下限（免得手指还没感觉到"按住"音就过去了）
  hold_grace         按住时手指短暂松开的宽限（秒），默认 0.20
                     这个时间内又按回来不算断，嫌容易断就调大（如 0.3）
  follow_rate        跟随模式倍速，默认 1.0 = 100%，范围 0.2 ~ 2.0（20% ~ 200%）
                     平时用 Shift+↑/↓ 调就行，改这里也可以
  countdown_seconds  跟随演奏模式开始前的倒计时秒数，默认 3
  hotkeys            各个快捷键，例如 "save_song": "shift+f3"
                     ★ 一个动作可以写多个备选键，用竖线 | 隔开：
                       想让别的键也能触发，就在这行后面接着加（| 分隔），例如
                       "toggle_visible": "shift+f6|shift+f2|ctrl+h"
                       （上面这句 = Shift+F6、Shift+F2、Ctrl+H 三个都能隐藏/恢复）
                       同一个键位内部用加号 + 表示"要同时按下"，例如 "ctrl+alt+q"

改完保存，重新启动程序生效。

【常见问题】

Q: 按某个键没反应？
A: 先看面板上那行"输入检测"，按一下键：
   · 如果它显示了"检测到：X" → 程序读到了你的键，只是这个键不是当前该按的那个
     （块上写着要按哪个键，看块就行）
   · 如果什么都没显示 → 这个键没有被程序监听，检查 config.json 的 note_keys
     （第 8 个通道默认是逗号键 comma）

Q: 记不住 z x c v b n m , 对应简谱哪个音？
A: 1=z 2=x 3=c 4=v 5=b 6=n 7=m 8(高音1)=,

Q: 窗口挡住我点游戏了？
A: 正常不会——右边音符区永远鼠标穿透。如果面板挡到你，按 Shift+F10 让它也穿透。

Q: 录完按 Ctrl+S 怎么没保存？
A: Ctrl+S 是 Windows 的"窗口快捷键"，只有小窗口在最前面时才生效。
   最省事的办法：直接按 Shift+F3（游戏在前台也能按）。或者用鼠标点一下小窗口再按 Ctrl+S。

Q: 快捷键会不会和我游戏里的按键冲突？
A: 不会。程序只是"看一眼你按了什么"，不会拦下按键，游戏该收到还是收到。
   ★ 而且所有 F 区快捷键都要求**按住 Shift**（Shift+F3 / Shift+F5 ~ Shift+F12），
     所以你在游戏里直接按 F4~F12 时，本程序完全不会有反应 —— 这就是防冲突的设计。
   如果连 Shift+F 也想换，用记事本打开 config.json 改 hotkeys 即可，例如
   把 "save_song": "shift+f3" 改成 "f3"（去掉 shift+ 就退回成单键）。

Q: 曲谱太多了，列表里怎么翻？
A: 曲谱多到一屏放不下时，列表右边会自动出现滚动条。
   鼠标滚轮、拖滑块、点滚动条空白处都能翻。当前曲目会一直保持在可见范围内。

Q: 为什么按键没反应 / 窗口时有时无？
A: 两个已知条件（实测总结）：
   ① 游戏要开「无边框窗口 / 窗口化」模式——独占全屏时置顶窗口会被游戏盖住；
   ② 程序要用「以管理员身份运行」启动（右键 exe → 属性 → 兼容性 → 勾选，
      或右键 → 以管理员身份运行）——否则游戏全屏时按键可能读不到。
   都满足后，正常窗口化玩就一切正常。

Q: 我把曲谱文件夹换走了，原来的曲谱还在吗？
A: 在。换文件夹只是"改去哪儿读、往哪儿写"，不会删任何文件。
   想用回原来的，再点【曲谱文件夹…】选回程序旁边的 songs 就行。

【安全说明】

  不安装键盘鼠标钩子、不模拟按键、不发送任何输入
  不读取游戏内存、不注入游戏进程、不联网
  只用 Windows 自带的 GetAsyncKeyState 读一下按键和鼠标键状态
  在屏幕上画一个普通的置顶半透明窗口

简单说：它就是一个"画在屏幕上的画板"，加上"看一眼你按了什么"。
